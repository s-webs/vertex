# VERTEX Elevator — HTML UI

Откройте `index.html` в браузере. Страницы: главная (`index.html`), каталоги (`catalog.html`), о компании (`about.html`), контакты (`contacts.html`).

Tailwind CSS, Phosphor Icons, шрифт Manrope, фотография Unsplash и карта OpenStreetMap загружаются через интернет. Основное оформление находится в `assets/styles.css`, интерактивность — в `assets/app.js`.

Работают мобильная навигация, фильтрация каталога, модальные описания и встроенная проверка формы. Форма демонстрационная: данные не отправляются и не сохраняются. Карта обзорная, без отметки офиса. Реальные контакты, документы, награды и подтверждённые характеристики оборудования необходимо предоставить перед публикацией.

HTML можно редактировать напрямую. Для повторной генерации всех страниц из общего шаблона: `node UI/generate.cjs` из корня проекта (перезаписывает HTML). Проверка локальных ссылок: `node UI/check.cjs`.
